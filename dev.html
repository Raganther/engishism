Commands worth keeping

Ask the code, never a list somebody typed — both of these read the registries, so a round or a helper added next month appears in them with nobody editing anything.

node tools/shelf.js            # every shared helper a round or a game can call
node tools/question-types.js   # every question shape content may be authored in

Before pushing. Match the check to what the change can break — a gate that always costs 25 minutes is a gate that gets skipped.

node tools/check-syntax.js                                        # seconds, always
NODE_PATH=$(npm root -g) node tools/smoke-test.js --only=content  # ~20s, any bank edit
NODE_PATH=$(npm root -g) node tools/smoke-test.js --only=qbench,grouping,card,gameshow
NODE_PATH=$(npm root -g) node tools/smoke-test.js                 # everything, ~25 min

Shipping. The stamp is found by search, never a list — and the 20YYMMDD shape is load-bearing, because classic.html carries ?v=picture and a looser pattern rewrites it into a broken page.

sed -i "s/?v=20[0-9]\{6\}[a-z]*/?v=$(date +%Y%m%d)a/g" $(grep -rl '?v=20[0-9]\{6\}' --include=*.html . | grep -v node_modules)
git add -A && git commit -m "..." && git push      # live in about 40 seconds
